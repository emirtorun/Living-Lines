AI-Powered Animated Comic Generator
A single-page web application that turns static character drawings into interactive, animated comic adventures using generative AI.

✨ Key Features
Bring Drawings to Life: Upload a 2D character drawing; the AI animates it while maintaining perfect visual consistency (no redisigning/morphing).

Interactive Storytelling: Branching narratives where users choose "what happens next."

Hybrid AI Pipeline: Uses GPT-4o for story generation and Runware (Bytedance Seedance) for rapid video generation.

No Build Required: Runs entirely in the browser using React/Babel via CDNs.

🛠 Prerequisites
You need API keys for the following services:

OpenAI API Key: For story generation and vision analysis (GPT-4o).

Runware API Key: For fast image-to-video generation.

🚀 Quick Start
Download the .html file.

Open it directly in any modern web browser (Chrome/Firefox recommended).

Enter your OpenAI and Runware API keys in the setup screen.

Upload a character drawing (or use text mode) and start your adventure.

🧩 Tech Stack
Frontend: React 18 (CDN), Tailwind CSS

AI Logic: OpenAI GPT-4o

AI Media: Runware API (Bytedance Seedance 1.0 Pro Fast model)
